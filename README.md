# Hospital-Readmission-Prediction
*Project Overview:*

This project aims to analyze hospital patient data to identify the key factors associated with hospital readmissions and develop a Machine Learning model to predict the likelihood of a patient being readmitted within 30 days of discharge.

*Project Objectives:*

* Analyze patient admission and discharge patterns.
* Identify factors associated with hospital readmissions.
* Analyze patients' length of stay and previous hospital visits.
* Develop a predictive model to identify patients at higher risk of readmission.
* Build an interactive Power BI dashboard to visualize key healthcare KPIs and support data-driven decision-making.

*Tools & Technologies:*
Python, Pandas, SQL, Machine Learning, and Power BI.

*Expected Outcome:*

An integrated analytical solution that helps healthcare providers understand readmission patterns, identify high-risk cases, and support efforts to improve patient care and reduce avoidable hospital readmissions.
